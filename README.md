# SmartReserva 🏨

> Trabalho de Conclusão de Curso (TCC)

O **SmartReserva** é um sistema inteligente de gestão e reserva de ambientes/equipamentos, composto por um aplicativo móvel e uma API de inteligência artificial.

---

## 📱 Estrutura do Projeto

O repositório está dividido em duas partes principais:

*   **`meu-app/`**: Aplicativo mobile desenvolvido em **React Native** (Expo) para que os usuários realizem e gerenciem suas reservas.
*   **`python-api/`**: API de backend desenvolvida em **Python** responsável pelo processamento inteligente de dados, inteligência artificial e regras de negócio.

---

## 🛠️ Tecnologias Utilizadas

### Frontend (Mobile)
*   React Native / Expo
*   TypeScript / JavaScript
*   Axios (Integração com a API)

### Backend (API)
*   Python
*   Git LFS (Gerenciamento de datasets/modelos pesados)

---

## 🚀 Como Executar o Projeto Localmente

### 1. Pré-requisitos
*   Node.js instalado
*   Python 3.x instalado

### 2. Rodando o Aplicativo (React Native)
```bash
cd meu-app
npm install
npx expo start
```

### 3. Rodando a API (Python)
```bash
cd python-api
# Ative seu ambiente virtual (venv) se houver
pip install -r requirements.txt
python main.py
```
